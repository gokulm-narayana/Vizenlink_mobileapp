# Features Index

One row per compiled Feature. Updated by the `compile_features` command / the `dev-workflow`
skill's "Feature Compilation (Seed → Feature)" procedure — see
[.claude/skills/dev-workflow/SKILL.md](../../.claude/skills/dev-workflow/SKILL.md).

`Title` is a short name (matching the `FR-CF-NNN — Title` convention used as headings in every
`FR-*.md` doc, and the `Title` column in `bugs/INDEX.md`) — what gets referenced elsewhere and
what a `FEAT-NNN-slug.md` companion filename's slug derives from. `Description` is one
additional line of context Title alone can't carry.

Seed IDs are kept permanently for traceability back to the seed doc — never remove them even
if a Feature's scope is later narrowed. `Origin` distinguishes seed-sourced rows (`Seed`) from
ones the gap scan inferred from the doc's prose with no backing seed ID (`Inferred —
§<section>`, `Seed IDs` = `—`) — see "Gap scan" in the skill. A Feature with real discussion or
conflict history worth preserving gets an optional companion file `FEAT-NNN-slug.md` (mirrors
`design/stages/*/bugs/NNN-slug.md`), linked from the Notes/File column — **mandatory** for
every `Inferred` row, optional for `Seed`-origin rows.
